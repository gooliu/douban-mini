更新豆瓣登录

豆瓣把「加入的小组 / 完整发言」设为仅本人可见，需要登录态 token。 token 有效期有限，失效后在这里粘贴新 token 即可，不用重启服务。 不登录也能用：用户信息、小组搜索、反查发帖 / 回帖（公开数据）。

方式一：Bearer token（手机抓包）
方式二：网页 Cookie（电脑浏览器，更省事）
方式一：怎么抓 token？（三步）
  1. 手机装抓包 App：HTTPCanary（安卓）或 Stream（iOS）， 并安装/信任它的 CA 证书。
  2. 打开抓包 → 只选「豆瓣」App → 打开豆瓣 App 并确认已登录，随便刷一下首页。
  3. 在抓包记录里找 frodo.douban.com 的请求， 看请求头 Authorization: Bearer xxxx， 把 Bearer 后面那串复制出来粘到上面。
方式二：怎么复制 Cookie？（推荐，有效期更长）
① 一键小书签（最省事，不用 F12）

把下面这个按钮拖到浏览器的书签栏（书签栏没显示就按 Ctrl+Shift+B 调出来）：

📋 一键登录豆瓣

之后：打开 www.douban.com 登录 → 点一下书签栏上的 「📋 复制豆瓣Cookie」→ 弹窗说已复制 → 回来粘到上面的 Cookie 框。 拖不动的话，右键按钮选「复制链接地址」，手动新建书签粘贴进去。

② 手动复制（开发者工具）
  1. 电脑浏览器打开 www.douban.com 并登录。
  2. 打开开发者工具：Ctrl+Shift+I（或 F12； 页面空白处右键 → 检查；菜单 → 更多工具 → 开发者工具）。
  3. 切到 Application（应用）→ 左侧 Cookies → https://www.douban.com。
  4. 找到 dbcl2，复制它的值（形如 "281065007:xxxxxxxx"）， 粘到上面 Cookie 框；再在「你的 uid」里填 281065007。

F12 没反应？常见原因：① 在预览面板 / 小程序里按的—— 请用自己电脑的 Chrome 或 Edge 打开 http://127.0.0.1:8000/； ② 笔记本要按 Fn+F12；③ 直接改用上面的小书签，完全不用开发者工具。

Cookie 有效期通常远长于 frodo token（token 常常一小时内就失效）， 全量扫描动辄几十分钟，建议优先用 Cookie。

凭证只保存在本机 backend/douban_config.json，不会上传到任何地方。

别人访问这台机器上的工具时，看到的「我加入的小组 / 我的发言」就是你的账号数据。 如果不想暴露，先点下面的「退出登录」再分享；退出后公开功能（查他人、反查、小组搜索）照常可用。
📱 加到手机桌面（像 App，不用小程序、不用审核）
对方用手机浏览器打开上面的地址后：
iPhone（Safari）：底部分享按钮 ↑ → 「添加到主屏幕」
安卓（Chrome / Edge）：右上角 ⋮ → 「添加到主屏幕」/「安装应用」
之后桌面会出现一个绿色「豆」图标，点开就是全屏无地址栏，和小程序体验几乎一样， 还不用备案域名、不用过微信审核。
不在同一个 WiFi？用内网穿透（外网也能访问）
双击项目目录里的 内网穿透分享.bat，会引导你用 cpolar 或 Cloudflare Tunnel 生成一个公网网址， 发给任何人都能打开（不要求同 WiFi）。
注意：网址是临时的，用完记得关掉，别长期暴露在公网上。
想彻底长期分享？部署到服务器
买一台云服务器（腾讯云 / 阿里云轻量，几十块一个月）， 把 douban-mini/ 整个目录拷上去，装 Python 依赖后运行 uvicorn main:app --host 0.0.0.0 --port 8000， 再在安全组放行 8000 端口，就有一个永久可访问的地址了。
提醒：豆瓣对异地 IP 的风控更严，部署到云服务器后建议用 Cookie 登录。
