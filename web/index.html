登录后才能看「我加入的小组 / 我的完整发言」，回帖反查也需要登录。 公开查询（用户资料、小组、他人发帖反查）不用登录。

已经有 Bearer token 就粘在这里；直接粘整段抓包文本也行，会自动提取。

token 从哪来？（抓包，安卓 / iOS 都能做）
  1. 手机装抓包 App：HTTPCanary（安卓）或 Stream（iOS），并信任它的证书。
  2. 只抓「豆瓣」App → 打开豆瓣随便刷一下首页。
  3. 找 frodo.douban.com 请求头里的 Authorization: Bearer xxxx，复制 Bearer 后面那串。

在已经登录的电脑上生成一个 6 位码，手机上输入它就能登录 —— 不用在手机上粘长串 token。

① 在电脑上（本页已登录）生成码
② 在手机上输入电脑显示的 6 位码

接力码 5 分钟内有效、只能用一次。

推荐，手机电脑都能用：把你浏览器里的豆瓣 Cookie 复制过来。 豆瓣的登录标识 dbcl2 是 HttpOnly，脚本读不到， 所以只能手动复制一次 —— 复制完一直有效，直到你在豆瓣退出登录。

① 浏览器打开 douban.com 并登录你的账号
② 按 F12 →「应用 / Application」→ 左侧 Cookie → douban.com
③ 复制 dbcl2 和 ck 的值，按下面格式粘进输入框

⚠️ 必须含 dbcl2；多个 Cookie 之间用英文分号隔开， dbcl2 值自带的引号要保留；无痕窗口 / 另一个浏览器的 Cookie 无效。

找不到「应用」在哪？点开看详细步骤
  1. 打开 douban.com 登录 → 按 F12（笔记本按 Fn + F12）。
  2. 顶部一排标签里选「应用」（英文界面叫 Application； 看不到就点最右边的 >>，标签都收在里面）。
  3. 左边一列找到「存储 → Cookie」→ 点 https://www.douban.com。
  4. 右边出现表格，双击 dbcl2 那一行的值复制，再把 ck 也复制出来。
  5. 按上面输入框里的格式拼好粘进来，点「验证并登录」。

手机上没法按 F12：先在电脑上登录成功， 再用「手机接力」生成一个 6 位码，手机输入即可。

ℹ️ 说明：豆瓣 App 接口只认 Bearer token， 所以 Cookie 走的是移动网页通道（m.douban.com）。加密的是你自己的登录态， 只存在你这个浏览器里。

打不开？多半是 Windows 防火墙拦了：右键用管理员身份运行项目目录里的 分享给他人.bat，它会自动放行 8000 端口。
📱 加到手机桌面（像 App，不用小程序、不用审核）
对方用手机浏览器打开上面的地址后：
iPhone（Safari）：底部分享按钮 ↑ → 「添加到主屏幕」
安卓（Chrome / Edge）：右上角 ⋮ → 「添加到主屏幕」/「安装应用」
之后桌面会出现一个绿色「豆」图标，点开就是全屏无地址栏，和小程序体验几乎一样， 还不用备案域名、不用过微信审核。
不在同一个 WiFi？用内网穿透（外网也能访问）
双击项目目录里的 内网穿透分享.bat，会引导你用 cpolar 或 Cloudflare Tunnel 生成一个公网网址， 发给任何人都能打开（不要求同 WiFi）。
注意：网址是临时的，用完记得关掉，别长期暴露在公网上。
想彻底长期分享？部署到服务器
买一台云服务器（腾讯云 / 阿里云轻量，几十块一个月）， 把 douban-mini/ 整个目录拷上去，装 Python 依赖后运行 uvicorn main:app --host 0.0.0.0 --port 8000， 再在安全组放行 8000 端口，就有一个永久可访问的地址了。
提醒：豆瓣对异地 IP 的风控更严，部署到云服务器后建议用 Cookie 登录。
